# CyberSheild-AI
🛡️ CyberShield AI

AI-Powered Scam and Phishing Detector

CyberShield AI is a cybersecurity project designed to analyze suspicious messages, identify common scam warning signs, and help users make safer decisions online.

🚀 Features

- Analyzes messages for suspicious keywords and phrases.
- Assigns a risk score from 0 to 100.
- Displays a risk level and detected warning signs.
- Provides safety recommendations to users.
- Includes test cases for scam messages and normal messages.

🛠️ Technology Stack

- Python
- Streamlit (if used by the application)
- Rule-based text analysis

▶️ How to Run

1. Install Python.

2. Clone this repository:
   
   "git clone https://github.com/nischithhg5-maker/CyberShield-AI.git"

3. Open the project folder:
   
   "cd CyberShield-AI"

4. Install the required dependencies listed in "requirements.txt", if provided.

5. Run the application using the appropriate command for the framework configured in "app.py".

🧪 Example Test Cases

- Prize or lottery scam messages.
- Messages requesting OTPs or verification codes.
- Normal college meeting announcements.

🔒 Safety Note

This project is an educational demonstration. Risk scores are based on the current detection rules and do not guarantee that a message is safe or fraudulent.

👨‍💻 Project Goal

To promote digital safety by helping users recognize potential online scams and phishing attempts.
